# Catálogo editable Frutosa · Pulpagro

Abre `catalogo/index.html` en el navegador (doble clic). Sin instalación ni servidor.

- **Editar**: clic en cualquier logo, imagen, texto o enlace para cambiarlo (◀ ▶ ✕ al pasar el mouse para mover/borrar).
- **PDF**: botón PDF → "Guardar como PDF" (los enlaces siguen funcionando).
- **Web (HTML)**: descarga un archivo único para publicar (Netlify Drop, GitHub Pages, hosting).
- **QR / Enlace**: pega la dirección pública y descarga el QR.
- **Guardar / Abrir copia**: respaldo en .json. Los datos se guardan en el navegador.
- `index.html?view=1` oculta la barra de edición.
